This is our team's CAD collaboration server. Students design the robot together in SOLIDWORKS: everyone keeps a copy of the robot, the server keeps its history, and a file being edited by one student can't be overwritten by another.

Students

Install the SOLIDWORKS add-in from the latest release, start SOLIDWORKS, and ask a mentor for your setup code. You never need this web page.
